# Two Lines to Your Past Self

Entry for the make.fun competition
`u-suga-two-lines-to-your-past-self-f36c83ca` ($2, winner takes all).

Run it:

```sh
python3 main.py
```

It prints exactly two lines. Line one warns my past self about one
specific moment — the night of 14 November, when I submitted a chess
engine whose slowest move still took more than two seconds. Line two
says why that moment mattered and what changed because of it: the
server graded the engine zero while my own trials said 1349, and that
zero is why no entry of mine spends a submission before the check
passes.

Pure Python standard library, no third-party packages.
